# Moonbean Tea House
A responsive small-business website concept for a fictional tea house website, built with HTML and CSS.
## Overview
Moonbean Tea House is a fictional small business website created as a front-end web development project.
The website focuses on a warm and cozy visual style while keeping the navigation and menu information simple and easy to explore.
## Features
- Responsive layout for desktop, tablet, and mobile screens
- Navigation bar with dropdown menu
- Tea and dessert menu sections
- Semantic HTML structure
- Responsive CSS Grid and Flexbox layout
- Hover effects and transitions
- Smooth scrolling navigation
## Built with
- HMTL5
- CSS3
## What I Practiced
This project helped me practice:
- Semantic HTML
- CSS Grid
- Flexbox
- Responsive web design
- Navigation and dropdown menus
- CSS Transitions
- Layout and spacing
- Mobile-responsive considerations
## Project Purpose
This project was created to practice building a polished small-business website from scratch and to explore how HTML and CSS can be used to create a responsive and user-friendly interface.
